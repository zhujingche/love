# 江鑫颖姐姐的专属空间

手机打开即用的小站，底部四个模块：**首页 / 情话 / 消气 / 憨豆**。

## 在线地址

- 她的页面：**https://zhujingche.github.io/love/**
- 你看留言：**https://zhujingche.github.io/love/read/**

## 四个模块

### 🏠 首页
- 标题「江鑫颖姐姐的专属空间」
- 在一起第 N 天（2026-08-30 为第 1 天，每天零点自动 +1）+ 实时时长
- 每天一句情话（每天固定一句，可点「换一句」）
- 爱心余额 + 每日签到（+5 💗）
- 憨豆状态速览

### 💌 情话
- 今天的情话
- 「我想要朱景澈牢牢记住的事」+「我不喜欢的事」两个输入框，自动保存在她手机上
- 点「写好了，让他知道」→ 推送给你

### 😤 消气
- 选生气程度（🙂 一点点 / 😐 有点气 / 😠 很生气 / 🤯 超生气）
- 写「因为什么事」+「要朱景澈做什么才能消气」
- 点「发给他」→ 你会收到包含程度与诉求的推送；她这边也留一份历史

### 🐣 憨豆（桌宠）
- 一只小宠物，会说话、会跳、会随机冒话逗她
- **喂食**（+2💗）· **摸摸头** · **玩游戏**（猜拳，赢 +3💗）· **铲屎**（+2💗/坨）
- **会拉屎**：每 25 分钟一坨，最多 6 坨；不铲心情和观感都会变差
- 饱食度每 20 分钟 -1，饿久了心情下降
- **换装系统**：帽子 / 眼镜 / 衣服 / 装饰共 13 件，用爱心兑换，点一下穿上或脱下
- **爱心来源**：签到 +5、喂食 +2、铲屎 +2/坨、猜拳赢 +3

## 推送怎么工作

她写「情话」或「消气」点发送 → 通过 **ntfy**（免注册服务）推给你：

1. **装 ntfy App**（安卓应用商店 / iOS App Store 搜 `ntfy`），订阅主题 `jxy-love-2c2d8f7e9f5d`
2. 或者直接打开 **https://zhujingche.github.io/love/read/**（每 15 秒自动刷新，打开过的都会存进本地存档，可导出）

> 备用通道：PushPlus / Server酱（页面里已接好，`?setup=1` 填 token 即可；PushPlus 需先完成实名认证）

## 怎么改

| --- | --- |
| 在一起的日期 | `const START = new Date(2026, 7, 30);`（月份从 0 开始，7 = 8 月；这天算第 1 天） |
| 情话内容 | `const QUOTES = [...]` |
| 憨豆会说的话 | `const PET_LINES = [...]` |
| 商店物品与价格 | `const SHOP = [...]`（`p: 0` 表示免费默认拥有） |
| 推送主题 | `const NTFY_TOPIC = '...'` |

## 技术说明

- 纯静态单页（原生 HTML/CSS/JS，零依赖），所有数据存在她手机本地（localStorage），不上传第三方
- PWA：`manifest.webmanifest` + `sw.js`（可加到主屏幕、支持离线打开）
- 图标：`make_icons.py`（Pillow 生成）
- 页面已设 `<meta name="robots" content="noindex, nofollow">`，不被搜索引擎收录
