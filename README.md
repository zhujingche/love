# 小站 💗

只给一个人看的小站 · 手机打开即用。

## 在线地址

**https://zhujingche.github.io/love/**

## 里面有什么

- 顶部「**恋爱第 N 天**」：每天 0 点自动 +1，无需维护
- 实时在一起的时长（天 / 时 / 分 / 秒，每秒跳动）
- 距离第 100 天的倒计时
- 每日一句情话（同一天固定，每天自动换一句）
- 我们的照片位
- 「点我一下」彩蛋：爱心爆炸 + 写给她的话
- 粉色漂浮爱心、原创可爱小猫、蝴蝶结

## 怎么改

**1. 改在一起的纪念日**（最重要）

打开 `index.html`，找到这一行：

```js
const START = new Date(2026, 7, 30);   // 月份从 0 开始：7 = 8 月
```

`2026, 7, 30` 表示 **2026 年 8 月 30 日**，这天算「第 1 天」。改成真实的纪念日即可，天数会自动计算。

**2. 放合照**

把照片命名为 `photo.jpg` 放在本目录（与 `index.html` 同级），页面会自动显示。

**3. 改情话 / 问候语**

- 情话列表：`index.html` 里的 `const QUOTES = [...]`
- 打招呼文字：函数 `renderGreet()` 里的 `g`（问候）与 `m`（正文）

## 怎么让她最方便地打开

| 方式 | 做法 |
| --- | --- |
| 微信发链接 | 把上面的地址发给她，点一下即可打开 |
| **加到主屏幕** | iPhone：Safari → 分享 → 「添加到主屏幕」；Android：Chrome/夸克 → 菜单 → 「添加到主屏幕」。桌面会出现粉色爱心图标，点开全屏、**断网也能看** |
| 扫二维码 | 扫描仓库或桌面上的 `小站二维码.png` |

## 技术说明

- 纯静态单文件页面（原生 HTML/CSS/JS，零依赖），无任何用户数据采集
- 支持 PWA：`manifest.webmanifest` + `sw.js` 提供「加到主屏幕」与离线缓存
- 图标由 `make_icons.py` 用 Pillow 生成

## 隐私

页面为公开访问（知道链接即可打开），已在页面中设置 `<meta name="robots" content="noindex, nofollow">` 避免被搜索引擎收录。
