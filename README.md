# 小站

只给一个人看的小站 · 手机打开即用。

## 在线地址

**https://zhujingche.github.io/love/**

## 页面内容

- 顶部「**恋爱第 N 天**」：2026-08-30 在一起（这天算第 1 天），每天零点自动 +1
- 在一起时长（天 / 时 / 分 / 秒，每秒跳动）
- 每天一句（同一天固定，每天自动换一句）
- **三个记录模块**（她自己写，内容自动保存在她手机的浏览器里）：
  - 最近不开心的事
  - 最近开心的事
  - 我想要朱景澈牢牢记住的事
- 「复制这三段，发给朱景澈」按钮：一键把上面三段复制到剪贴板，粘到微信即可发我
- 「点我一下」彩蛋

> 说明：三个记录模块的内容保存在**她手机的本地存储**里（不会上传到网上，别人看不到）。
> 想让你看到时，她点一下复制按钮，粘贴发给你就行。

## 怎么改

**1. 改在一起的日期**

`index.html` 中：

```js
const START = new Date(2026, 7, 30);   // 月份从 0 开始：7 = 8 月，即 2026-08-30
```

这天算第 1 天；天数会自动计算并每天 +1，不需要维护。

**2. 改每天一句 / 问候语**

- 句子列表：`index.html` 里的 `const QUOTES = [...]`
- 问候语：函数 `renderGreet()` 中的 `g`（问候）与 `m`（正文）

**3. 改三个模块的标题**

`index.html` 里搜「最近不开心的事」等文字，直接改即可（同时改 `NOTES` 数组里的 `title`，复制出来的文字会跟着变）。

## 怎么让她最方便地打开

| 方式 | 做法 |
| --- | --- |
| 微信发链接 | 把上面地址发给她，点一下即可打开 |
| **加到主屏幕** | iPhone：Safari → 分享 → 「添加到主屏幕」；Android：Chrome/夸克 → 菜单 → 「添加到主屏幕」。桌面出现粉色爱心图标，点开全屏、**断网也能看** |
| 扫二维码 | 扫描 `小站二维码.png` |

## 技术说明

- 纯静态单文件页面（原生 HTML/CSS/JS，零依赖），不采集任何用户数据
- PWA：`manifest.webmanifest` + `sw.js` 提供「加到主屏幕」与离线缓存
- 图标由 `make_icons.py`（Pillow）生成

## 隐私

页面为公开访问（知道链接即可打开），页面中已设置 `<meta name="robots" content="noindex, nofollow">` 避免被搜索引擎收录。
